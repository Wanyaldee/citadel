# Code of Conduct

Citadel is an independent, non-commercial fork of Zed and is not affiliated with Zed Industries, Inc. — see [legal/NOTICE.md](./legal/NOTICE.md). This project has its own Code of Conduct, separate from Zed's.

This applies to all project spaces: GitHub issues, discussions, and pull requests, and (once it's live) the Citadel Discord server.

## Our standard

- Be respectful. Disagree on technical points without attacking the person.
- Keep discussion focused and constructive — this is a small, hobbyist/embedded-focused project, not a place for unrelated debate.
- No harassment, hate speech, or personal attacks, in any project space.
- Assume good faith, especially with non-native English speakers and first-time contributors. (The maintainer isn't a native English speaker either, so we're all in this together.)

## Reporting

If you experience or witness unacceptable behavior in any Citadel space, report it by opening a private communication with the maintainer via GitHub (e.g. a direct message or a issue marked confidential where supported), or through the Discord server's reporting tools once it is available.

Reports will be handled as promptly as possible given this is a maintained-in-spare-time project. Confidentiality of the reporter will be respected.

## Enforcement

Maintainers may remove, edit, or reject comments, commits, code, issues, and other contributions that violate this Code of Conduct, and may temporarily or permanently ban any contributor for behavior they deem inappropriate, threatening, offensive, or harmful.
